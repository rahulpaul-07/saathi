# Recording scripts (optional, not needed)

The project no longer records anyone. Address-fact audio is Gnani TTS ("clean synthetic"), real
human speech is the FLEURS public dataset, and the demo video shows no people (see
`docs/EVAL.md`, "Audio sources and labels"). The three scripts here are kept only in case someone
later volunteers to read them; nothing in the evaluation, the demo or the budget depends on them.
Any such recordings would stay in the gitignored `eval/audio/` and be reported as consented human
speech.
